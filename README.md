# WordPress Code Snippets

A collection of small, production-tested WordPress / WooCommerce snippets — CSS, PHP,
and JS solutions to real store problems. Each snippet lives in its own folder with a
short README explaining what it does and how to use it.

## Snippets

| Snippet | Description |
| ------- | ----------- |
| [store-credit-button-reposition](store-credit-button-reposition/) | Repositions the WooCommerce "Apply Store Credit" button on the cart page (below coupons on desktop, top of totals on mobile) with pure CSS. |
| [trash-past-workshops-cron](trash-past-workshops-cron/) | Hourly WP-Cron job that trashes expired `workshops` CPT entries after 5pm site time on the event date. |
| [recurring-events-acf](recurring-events-acf/) | Recurring + multi-day event system on ACF fields: occurrence expansion, `[evt_upcoming_events]` grid shortcode, Elementor loop filter. |
